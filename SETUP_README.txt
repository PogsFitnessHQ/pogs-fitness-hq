POG’S FITNESS HQ — V29 GitHub Pages

PUBLIC FILES: index.html, manifest.webmanifest, sw.js, icon.svg, icon-192.png, icon-512.png, apple-touch-icon.png

1. Back up your EXISTING app data using its JSON export first. Save the JSON privately (not in GitHub).
2. Upload the seven PUBLIC FILES above to the root of your public GitHub repository pogs-fitness-hq. Do NOT upload your personal JSON backup or the old HTML.
3. In GitHub repository Settings > Pages, choose Deploy from a branch, branch main, folder /(root), then Save.
4. Once published, open https://pogsfitnesshq.github.io/pogs-fitness-hq/ in iPhone Safari, then Share > Add to Home Screen > Open as Web App > Add.
5. Open the installed app and import your private JSON backup using the app’s import/restore controls. Check all workouts, measurements, PBs and drafts before switching away from Documents.

WARNING: GitHub Pages is public. This version intentionally has no embedded historical personal records; the user's own JSON data must be imported locally. Browser storage is per origin, not automatically transferred from Documents. Do not delete the original HTML, backup or Shortcut until verified.

Offline: the service worker caches app files after first successful load. First launch requires internet. On iOS, local storage is not a guaranteed permanent backup: export JSON regularly.
